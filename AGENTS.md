# Maintaining this collection

- This repo contains skills and documentation. Keep it simple; no custom installer
  or generated installation directories.
- Keep complete upstream skill folders intact unless an adaptation is documented.
  The interface family is one compact, explicit-only `better-ui` router;
  its `better-*` concepts are Markdown references, not nested skills. Keep Matt
  Pocock adaptations under `matt-pocock/`.
- Preserve supporting scripts, references, assets, and license notices.
- Keep linked companion skills together. Preserve the documented Matt Pocock
  adaptations when updating; project commands and domain constraints come from the target repo.
- Keep documentation concise. Use Conventional Commits when committing.
- When asked to set up the collection, discover folders containing SKILL.md
  recursively and link each one individually into the harness's supported location.
  Preserve existing installations and report name conflicts.
- This AGENTS.md applies to maintaining the repo; do not install it globally.
- Imported skills are artifacts being maintained. Do not execute their workflows
  merely because they are being added or updated here.
