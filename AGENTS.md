# Maintaining this collection

- Keep this a simple collection of skills and documentation; no custom installer
  or generated installation directories.
- Preserve complete upstream folders unless the adaptation is documented.
  Retain supporting scripts, references, assets, and license notices.
- Keep linked companion skills together and preserve their documented adaptations.
  Project commands and domain constraints come from the target repository.
- Keep routers compact and explicit-only. Their concepts are Markdown references,
  not nested skills; load only the references relevant to the request.
- Keep README.md and AGENTS.md at 48 lines combined or fewer. Avoid inventories and
  hardcoded references that drift as the collection changes.
- Use Conventional Commits.
- Install only when asked: discover SKILL.md recursively and link each containing
  folder individually into the harness's supported location. Preserve existing
  installations and report name conflicts.
- These instructions govern repository maintenance; do not install them globally.
- Imported skills are artifacts. Do not execute their workflows while maintaining them.
